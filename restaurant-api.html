ربط موقع المطعم بتوصيل سفيان

دليلٌ لمبرمج المطعم: كيف يرسل نظامكم (الموقع أو التطبيق) الطلبَ إلى كباتن سفيان مباشرةً بعد موافقة موظّفكم، وكيف تصلكم حالته.

Developer guide: send each order your staff approves from your website or app straight to Sufyan delivery dispatch, and receive its status back.

1. الفكرة في ثلاث خطوات

  1. الزبون يطلب من موقعكم، وموظّفكم يوافق على الطلب في نظامكم كالعادة.
  2. لحظة الموافقة يرسل خادمكم الطلب إلى سفيان (POST /v1/orders)، فيدخل التوزيع فوراً ويبحث له النظام عن كابتن، كأيّ طلبٍ من لوحة المطعم.
  3. كلّ تغيّرٍ في الطلب يصل خادمكم: قبل الكابتن، وصل المطعم، استلم، سُلّم، أُلغي. يصلكم إشعاراً على رابطكم، أو تسألون عنه متى شئتم.

Customer orders on your site → your staff approves → your server POSTs the order → a captain is dispatched immediately → status updates come back (webhook or polling).

2. العنوان والمفتاح

العنوان الأساسيّ (Base URL):

https://europe-west1-sufyan-delivery.cloudfunctions.net/restaurantApi

المفتاح: تعطيكم إدارة سفيان «رسالة الربط»، وفيها شيئان: مفتاح الربط (hut_live_…) وسرّ الإشعارات (hut_whsec_…). ضعوا المفتاح في ترويسة كلّ نداء:

Authorization: Bearer hut_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json

⚠️ نادوا الرابط من خادمكم فقط، لا من صفحةٍ يفتحها الزبون. المفتاح في صفحة الموقع يعني أنّ أيّ زائرٍ يقدر أن يرسل طلباتٍ باسمكم. ولهذا لا يقبل الرابط النداء من المتصفّح (لا CORS).

Call the API from your server only, never from browser JavaScript: the endpoint sends no CORS headers on purpose. Keep both secrets in server config.

3. إرسال طلب — POST /v1/orders

أرسلوه بعد موافقة موظّفكم، لا لحظة طلب الزبون: الكابتن يُطلب فوراً.

الحقلإلزاميّالشرح
refنعمرقم الطلب في نظامكم (١–٦٤ حرفاً: حروف وأرقام و. _ - # :). الرقم نفسه = الطلب نفسه: لو أعدتم الإرسال لا يتكرّر الطلب.
customer.phoneنعمموبايل الزبون: 07701234567 أو +9647701234567.
customer.nameلااسم الزبون.
addressنعمعنوان التوصيل كما كتبه الزبون: المنطقة، والشارع، وأقرب نقطة دالّة.
areaلااسم المنطقة. يُطابَق مع قائمة أسعار التوصيل لمطعمكم في سفيان، وإن غاب نبحث عن المنطقة داخل العنوان.
itemsهذا أو detailsالأصناف: [{"name":"شاورما","qty":2,"price":6000}] (السعر اختياريّ، بالدينار للقطعة). ستّون صنفاً على الأكثر.
detailsهذا أو itemsمحتوى الطلب نصّاً حرّاً، إن لم تكن عندكم أصنافٌ منفصلة.
totalنعمالمبلغ الذي يقبضه الكابتن من الزبون عند الباب، بالدينار، رقمٌ صحيح، كما في فاتورة الزبون. أرسلوا 0 إن دفع الزبون كلّ شيءٍ مسبقاً.
delivery_feeلاأجرة التوصيل التي حسبها موقعكم. إن غابت تؤخذ من قائمة أسعار مطعمكم في سفيان.
locationلا (يُفضَّل)دبّوس الزبون: {"lat":35.4712,"lng":44.3921}. يظهر للكابتن زرَّ «موقع الزبون».
map_linkلاأو رابط خرائط جوجل الذي أرسله الزبون (نستخرج منه الدبّوس).
notesلاملاحظة الزبون.
testلاtrue = تجربة: يُفحص الطلب ويُرجَع كما سيراه الكابتن، ولا يُنشأ ولا يُطلب كابتن. ابدؤوا بها.

مثال

curl -X POST "https://europe-west1-sufyan-delivery.cloudfunctions.net/restaurantApi/v1/orders" \
  -H "Authorization: Bearer hut_live_…" \
  -H "Content-Type: application/json" \
  -d '{
    "ref": "WEB-1001",
    "customer": { "phone": "07801234567", "name": "أحمد" },
    "address": "حي الواسطي، قرب جامع النور",
    "area": "حي الواسطي",
    "items": [ { "name": "شاورما", "qty": 2, "price": 6000 }, { "name": "كولا", "qty": 1, "price": 1000 } ],
    "total": 16000,
    "location": { "lat": 35.4712, "lng": 44.3921 },
    "notes": "بدون بصل"
  }'

الجواب — 201

{
  "ok": true,
  "order_id": "HUT-…",
  "ref": "WEB-1001",
  "status": "searching",
  "status_ar": "يبحث عن كابتن",
  "duplicate": false,
  "area": "حي الواسطي (توصيل: 3000)",
  "area_matched": "حي الواسطي",
  "delivery_fee": 3000
}

إن أعدتم إرسال الرقم نفسه (انقطع الاتصال مثلاً) يرجع الجواب 200 بالطلب نفسه و"duplicate": true، فلا خوف من الإعادة.

وarea_matched: null معناه أنّ المنطقة ليست في قائمة أسعاركم في سفيان، فالأجرة «غير مؤكّدة». أرسلوا delivery_fee، أو اطلبوا من الإدارة إضافة المنطقة.

بلغة PHP (مواقع ووردبريس وغيرها)

$order = [
  'ref' => 'WEB-' . $orderId,
  'customer' => ['phone' => $phone, 'name' => $name],
  'address' => $address,
  'items' => $items,            // [['name'=>'شاورما','qty'=>2,'price'=>6000], ...]
  'total' => (int) $totalToCollect,
];
$ch = curl_init('https://europe-west1-sufyan-delivery.cloudfunctions.net/restaurantApi/v1/orders');
curl_setopt_array($ch, [
  CURLOPT_POST => true, CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 20,
  CURLOPT_HTTPHEADER => ['Authorization: Bearer ' . HUT_KEY, 'Content-Type: application/json'],
  CURLOPT_POSTFIELDS => json_encode($order, JSON_UNESCAPED_UNICODE),
]);
$res = json_decode(curl_exec($ch), true);   // $res['ok'], $res['order_id'], $res['error']['message_ar']

4. حالة الطلب

ستّ حالاتٍ ثابتة الأسماء:

statusالمعنى
searchingيبحث عن كابتن
captain_assignedقبل الكابتن الطلب وهو في طريقه إلى المطعم (ومعه captain: الاسم والرقم)
at_restaurantالكابتن عند المطعم
picked_upاستلم الكابتن الطلب، وهو في الطريق إلى الزبون

  "status_ar": "قبل الكابتن الطلب وهو في طريقه إلى المطعم",

5. إشعارات الحالة (Webhook)

أعطوا إدارة سفيان رابطاً في خادمكم (https باسم نطاق)، أو ضعوه بأنفسكم:

POST /v1/webhook
{ "url": "https://your-site.iq/hut-webhook" }      // "url": null removes it

مع كلّ تغيّرٍ يصل رابطَكم POST بهذا الجسم:

{
  "event": "order.status",
  "order_id": "HUT-…",
  "ref": "WEB-1001",
  "status": "picked_up",
  "status_ar": "استلم الكابتن الطلب وهو في الطريق إلى الزبون",
  "captain": { "name": "علي", "phone": "07709999999" },
  "at": "2026-10-25T12:30:00.000Z"
}

ومعه ترويستان للتحقّق من أنّه منّا: X-Hut-Timestamp (بالملّي ثانية) وX-Hut-Signature، وهي sha256= ثمّ HMAC-SHA256 بـسرّ الإشعارات على timestamp + "." + body، والجسم هو النصّ كما وصلكم حرفاً (قبل أيّ تحويل).

  • ردّوا بـ2xx سريعاً. نعيد المحاولة مرّةً واحدة عند 5xx أو انقطاع الاتصال.
  • الحالة نفسها لا تُرسَل مرّتين. وإن فاتكم إشعارٌ فاسألوا بـGET.

التحقّق — Node.js

const crypto = require("crypto");
function fromHut(headers, rawBody, secret) {
  const ts = headers["x-hut-timestamp"], sig = headers["x-hut-signature"] || "";
  if (!ts || Math.abs(Date.now() - Number(ts)) > 5 * 60 * 1000) return false;
  const want = "sha256=" + crypto.createHmac("sha256", secret).update(ts + "." + rawBody).digest("hex");
  return sig.length === want.length && crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(want));
}

التحقّق — PHP

$raw  = file_get_contents('php://input');
$ts   = $_SERVER['HTTP_X_HUT_TIMESTAMP'] ?? '';
$sig  = $_SERVER['HTTP_X_HUT_SIGNATURE'] ?? '';
$want = 'sha256=' . hash_hmac('sha256', $ts . '.' . $raw, HUT_WEBHOOK_SECRET);
if (!hash_equals($want, $sig) || abs(round(microtime(true) * 1000) - (int) $ts) > 300000) { http_response_code(401); exit; }
$e = json_decode($raw, true);   // $e['ref'], $e['status'], $e['captain']['name']
http_response_code(200);

6. الإلغاء — POST /v1/orders/{ref}/cancel

مثل زرّ الإلغاء في لوحة المطعم: يُقبل في كلّ وقتٍ قبل أن يستلم الكابتن الطلب. بعد الاستلام يرجع 409 too_late، فاتّصلوا بالدعم.

8. الأخطاء

كلّ خطأٍ بالشكل نفسه، ومعه رسالةٌ بالعربيّة يمكن عرضها لموظّفكم:

{ "ok": false, "error": { "code": "phone", "message": "customer.phone: …", "message_ar": "…", "field": "customer.phone" } }
الرمزcodeالمعنى
401unauthorizedالمفتاح مفقود أو خاطئ أو بُدِّل.
403disabledأطفأت الإدارة الربط لمطعمكم.
404not_foundرقم طلبٍ لا نعرفه، أو مسارٌ خاطئ.
409restaurant_closedمطعمكم في «استراحة» أو موقوف في سفيان، فلا تُستقبل الطلبات الآن.
409too_lateالإلغاء بعد استلام الكابتن.
409in_progressالرقم نفسه قيد الإنشاء الآن. أعيدوا بعد ثوانٍ.
422اسم الحقلحقلٌ ناقص أو غير صالح، وfield يسمّيه.
429rate_limitedأكثر من ٦٠ نداءً في الدقيقة.
500serverعطلٌ مؤقّت. أعيدوا بالرقم نفسه، ولن يتكرّر الطلب.

9. قبل التشغيل

  1. جرّبوا بـ"test": true حتى يخرج الطلب كما تريدون، خاصّةً المنطقة وأجرتها.
  2. أرسلوا طلباً حقيقيّاً واحداً وأخبروا الإدارة لتتابعه معكم.
  3. ضعوا رابط الإشعارات وتأكّدوا أنّ التوقيع يُقبل عندكم.

Start with "test": true (validates and previews the order exactly as the captain will see it, without creating anything), then send one real order with the delivery company watching.

من الحوت · توصيل سفيان — للمطاعم المرتبطة بسفيان. المفتاح يُصدَر ويُبدَّل ويُطفأ من إدارة سفيان.
